# 💖 Will You Be My Valentine?

A cute, interactive, and romantic website to ask your special someone to be your Valentine!

## ✨ Features

- **Interactive Question**: A "Yes" and "No" button interface.
- **Playful "No" Button**: The "No" button runs away and changes text to convince them to say "Yes"!
- **Celebration Mode**: Confetti, happy music, and a photo gallery appear when they say "Yes".
- **Responsive Design**: Works on both desktop and mobile.
- **Customizable Photos**: Easily add your own memories to the gallery.

## 🛠️ Setup & Customization

1.  **Clone the repository**:
    ```bash
    git clone https://github.com/snayan06/my-valentine.git
    cd my-valentine
    ```

2.  **Add your photos**:
    - Place your photos in the `images/` directory.
    - Update the `index.html` file to reference your new photo filenames in the gallery section.

3.  **Deploy**:
    - Run the deployment script:
      ```bash
      ./deploy.sh
      ```
    - Or manually push to GitHub and enable GitHub Pages.

## 🚀 Deployment

The site is deployed via GitHub Pages.

1.  Go to **Settings** > **Pages** in your GitHub repository.
2.  Select `main` branch as the source.
3.  Your site will be live at: `https://snayan06.github.io/my-valentine/`
